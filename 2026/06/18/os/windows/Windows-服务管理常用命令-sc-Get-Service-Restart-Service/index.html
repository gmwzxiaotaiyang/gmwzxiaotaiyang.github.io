如果人在图形界面前，打开“服务”管理器当然可以。但如果你是通过 SSH 连到一台 Windows 机器，或者手边只有 CMD / PowerShell，命令行会更省事。

常见问题

1. 服务名和显示名是不是一回事？

不一定。

Windows 服务通常有：

  • 服务名
  • 显示名

很多时候两者一样，但也可能不同。sc query 输出里一般能看到：

如果两者不同，命令里优先使用 SERVICE_NAME。

2. 服务名有空格怎么办？

加引号。

这是最容易踩的坑。只要服务名里有空格，就别省引号。

3. 提示拒绝访问怎么办？

服务管理通常需要管理员权限。

如果你是在 SSH 里操作 Windows 服务，当前 SSH 用户也需要有足够权限。否则执行 stop、start、restart 时可能会失败。

可以先确认当前账号是否具备管理员权限，再执行服务管理命令。
