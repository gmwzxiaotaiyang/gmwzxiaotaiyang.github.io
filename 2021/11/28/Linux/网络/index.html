windows常用命令：网络，进程

发表于2021-11-28|更新于2026-03-17|windowcmd
|总字数:109|阅读时长:1分钟|浏览量:

获取无线网密码

netsh wlan show profile

netsh wlan show profile name=”{wlan name}” key=clear

获取公网IP

curl ipv4.icanhazip.com

curl httpbin.org/ip

curl ipconfig.io

查看电脑运行的所有端口

netstat -ano

查看电脑运行的指定端口

netstat -ano |findstr “{port}”

查看任务列表

tasklist

根据任务列表查看端口

tasklist|findstr “{port}”

根据PID杀死任务

taskkill /F /PID “{PID}”

根据进程名杀死任务区

taskkill -f -t -im “{进程名称}”
